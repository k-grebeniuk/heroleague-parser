# HeroLeague Parser

Web scraper на Python и Playwright для автоматизированного сбора
результатов забегов с сайта [HeroLeague](https://heroleague.ru/results).

## О проекте

Цель проекта — автоматизировать сбор данных о соревнованиях в рамках «Забег.РФ» с сайта HeroLeague.

Для этого scraper с помощью Playwright открывает страницу с результатами, находит доступные мероприятия, переходит на страницы отдельных соревнований, определяет доступные дистанции и последовательно собирает таблицы результатов участников. Полученные данные сохраняются в CSV-файлы.

## Возможности scraper

Scraper автоматически:

- открывает страницу с результатами HeroLeague;
- находит доступные соревнования в рамках «Забег.РФ»;
- переходит на страницы отдельных мероприятий;
- определяет доступные дистанции и отбирает поддерживаемые проектом;
- переключает дистанции и ожидает загрузки результатов;
- проходит по всем страницам таблицы участников;
- извлекает данные из таблиц результатов;
- сохраняет результаты каждого мероприятия в отдельный CSV-файл.

## Стек

- **Python** — основной язык проекта
- **Playwright** — автоматизация браузера и сбор данных с сайта
- **CSV** — сохранение результатов
- **Стандартная библиотека Python** — работа с файлами, путями и обработка данных

## Запуск

### 1. Установка зависимостей

Клонируйте репозиторий и установите зависимости:
```bash
pip install -r requirements.txt
```

### 2. Установка браузера Playwright

После установки Playwright необходимо установить Chromium:
```bash
playwright install chromium
```

### 3. Запуск scraper

Запустите проект:
```bash
python run.py
```

После запуска откроется браузер Chromium, scraper автоматически перейдёт на страницу результатов HeroLeague и начнёт сбор данных.

## Результат работы

После запуска scraper:

* формируется `events.csv` со списком найденных мероприятий;
* для каждого обработанного мероприятия создаётся отдельный CSV-файл с результатами участников;
* результаты собираются со всех доступных страниц таблиц и поддерживаемых дистанций;
* заголовки таблиц сохраняются на основе данных, предоставленных источником.

Структура и набор столбцов в CSV-файлах могут отличаться в зависимости от конкретного мероприятия.

## Ограничения источника

HeroLeague содержит результаты соревнований с различающейся структурой и доступностью данных.

В зависимости от мероприятия могут отличаться:

* доступность результатов;
* набор представленных дистанций;
* структура и состав столбцов таблицы участников.

Кроме того, scraper зависит от текущей структуры страниц HeroLeague. Изменение элементов интерфейса или структуры таблиц на сайте может потребовать корректировки scraper.

## Дальнейшее развитие

Опыт работы с данными HeroLeague стал основой для следующего проекта — [Running Insights](https://github.com/k-grebeniuk/running-insights), посвящённого сбору, обработке и анализу данных о забегах «Забег.РФ».

В нём задача была расширена от автоматизированного сбора данных до построения единого набора данных для последующего анализа и визуализации.
